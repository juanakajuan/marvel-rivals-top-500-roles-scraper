# marvel-rivals-top-500-roles-scraper

## Prerequisites

1. Python 3.x installed.
2. Google Chrome or Chromium browser installed.

## Installation

1. Set up the project: Open your terminal in the project folder.

2. Install required libraries:
```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage

Run the script:
```
python scraper.py
```
